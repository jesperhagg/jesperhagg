### How I work
I built an operating system that encodes how i think and work as modular, installable skills and agents. Each product repo encodes what to build, with its own domain context that keeps terminology and strategy cleanly separated across products.
The repo serves as the live data layer — Decisions, Personas, Opportunity Backlog, Tasks, Signals, Knowledge, and Leads are stored as markdown files directly in the repo, so every PM skill and agent operates on versioned, portable context that travels with the codebase.
I can spin up a new product and have my own preferred PM stack running against it immediately. The framework scales horizontally across products without cross-contamination.

#### Vor - Regulatory compliance automation for small-scale forestry
- Every forestry owner in Sweden need to send in a felling notice before a harvest, and small-scale forest owners spend a lot of time or money on this. There is currently no tools to support this process, it is completely manual and a struggle to navigate compliance.
- Fellingpal automates and supports this flow to reduce complexity and time spent for forestry owners and improve unit economics for forestry consultants.
